# Product Overview

This repository contains two distinct applications for Buddhist education and library management:

## Ebook Summary System (Python)
A desktop automation system that monitors the Buddhist Education website (budaedu.org) for new book releases, automatically downloads PDFs, generates AI-powered summaries using Google Gemini Pro 2.5, and distributes them via email. Features a Tkinter GUI for configuration and monitoring.

## LINE Book Query Bot (TypeScript/Node.js)
A smart library assistant that integrates LINE Messaging API with Google Gemini 2.5 Pro to help users query book databases using natural language. Provides intelligent book search capabilities through conversational interface with MySQL database integration.

Both applications leverage Google Gemini AI for intelligent content processing and are designed for Buddhist educational institutions to enhance their digital library services.
