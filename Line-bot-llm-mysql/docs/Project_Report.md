# 專案功能介紹與資源評估報告

## 1. 專案介紹 (Project Overview)

本專案是一個整合 **LINE Bot**、**AI 人工智慧** 與 **自動化爬蟲** 的智慧圖書館助理與資訊推播系統。旨在讓使用者透過最熟悉的 LINE 介面，以自然語言輕鬆查詢藏書，並即時接收新書與佛學課程的最新通知。

### 核心功能 (Key Features)

*   **🤖 智慧圖書查詢 (Smart Search)**：
    *   使用者可用口語化問句（如：「有沒有金剛經的書？」）詢問。
    *   系統透過 **Google Gemini AI** 理解使用者意圖，精準搜尋資料庫。
    *   搜尋結果以精美的卡片 (Flex Message) 呈現，支援圖片與詳細資訊瀏覽。
*   **📰 自動化資訊彙整 (Info Aggregation)**：
    *   **新書監控**：背後有機器人 24 小時監控網站，一旦有新書發布，自動下載 PDF、由 AI 生成摘要並發送通知。
    *   **課程/公告推播**：即時抓取最新佛學課程與停課通知。
*   **🔔 訂閱管理 (Subscription)**：
    *   使用者可自選訂閱類別（新書、新聞、停課通知）。
    *   支援 LINE 推播與 Email 電子報雙管道發送。
*   **🤳 LINE 官方帳號互動功能 (Official Account Features)**：
    *   **快速回覆按鈕 (Quick Reply)**：在歡迎訊息與對話中提供便捷按鈕，一鍵觸發以下功能，無需手動輸入指令：
        *   **📰 最新消息**：即時查看佛學課程與公告。
        *   **⚠️ 停課通知**：快速查詢近期是否有課程異動。
        *   **📚 最新法寶**：瀏覽最新上架的經書與佛卡。
        *   **🎬 最新影音**：獲取最新的講經說法影片連結。
    *   **圖文選單 (Rich Menu)**：(規劃中) 於聊天室底部常駐的圖像化選單，提供直覺的操作入口。

## 2. 測試與驗證流程 (Testing Strategy)

為確保系統穩定，我們採用多層次的測試策略：

*   **單元測試 (Unit Testing)**：針對系統中的最小功能模組（如：日期格式轉換、資料篩選邏輯）進行自動化檢查，確保邏輯無誤。
*   **整合測試 (Integration Testing)**：模擬真實情境，測試 LINE Bot 與 資料庫、Gemini AI 之間的連線與互動是否順暢。
*   **實機測試 (Manual Testing)**：開發人員直接使用手機 LINE App 進行對話測試，確保使用者體驗流暢。
*   **自動化監控 (Health Checks)**：系統上線後，具備自我健康檢測機制，若服務中斷能自動重啟或報警。

## 3. 上線與部署 (Deployment)

系統採用現代化的 **Docker 容器技術** 進行部署，具備以下優勢：

*   **快速安裝**：所有程式與環境（資料庫、AI 模組、網站伺服器）都打包在一起，像積木一樣一鍵啟動。
*   **環境一致性**：確保開發環境與正式主機環境完全一致，減少「在我電腦上可以跑」的問題。
*   **彈性擴充**：支援部署於雲端平台 (Google Cloud Run) 或 本地實體伺服器。

**上線流程簡述**：
1.  工程師將程式碼上傳至版本控制庫。
2.  自動化工具進行測試與打包 (Docker Image)。
3.  伺服器下載最新版本並重啟服務，過程通常僅需數分鐘。

### 硬體需求與成本 (Hardware Requirements)

本專案若考量未來導入 **本地端大型語言模型 (Local LLM)** 以取代雲端 AI（為了隱私或節省長期 API 費用），硬體規格將是關鍵成本。

#### 方案 A：輕量級/開發測試 (Entry Level)
*適用於：少量使用者、簡單查詢、測試環境*
*   **CPU**: Intel i5 / AMD Ryzen 5 (6核心以上)
*   **RAM**: 32 GB
*   **顯示卡 (GPU)**: **NVIDIA RTX 3060 / 4060 (12GB VRAM)**
    *   *說明*：可執行經過量化 (Quantized) 的 7B/8B 參數模型 (如 Llama 3 8B)。
*   **預估硬體成本**: 約 2.5 ~ 3.5 萬台幣

#### 方案 B：推薦規格/生產環境 (Recommended)
*適用於：正式上線、多人同時使用、需較快回應速度*
*   **CPU**: Intel i7 / AMD Ryzen 7 或 9 (8核心以上)
*   **RAM**: 64 GB (建議 DDR5)
*   **顯示卡 (GPU)**: **NVIDIA RTX 3090 / 4090 (24GB VRAM)**
    *   *說明*：24GB 記憶體是關鍵，可執行完整版 8B 模型或量化版 70B 模型，並支援較長的對話記憶 (Context Window)。
*   **預估硬體成本**: 約 6 ~ 9 萬台幣

#### 方案 C：企業級高效能 (Enterprise)
*適用於：極高併發量、微調模型 (Fine-tuning)、即時語音辨識 (FunASR)*
*   **GPU**: NVIDIA A6000 或 雙張 RTX 4090
*   **成本**: 20 萬台幣以上 (通常建議此等級租用雲端算力較划算)

### 總結建議
若初期預算有限，建議先使用雲端 AI API (Gemini/OpenAI)，免去購置昂貴顯卡的成本。待用量穩定或有隱私合規需求時，再採購 **方案 B (RTX 3090/4090)** 等級的主機進行本地化部署。
