# 網站監控系統 - 快速上線指南

## ✅ 系統已就緒

你的監控系統已經可以運行！剛才的測試顯示所有功能正常。

## 🚀 立即開始

### 方法 1：使用圖形選單（推薦）
雙擊執行：
```
START_HERE.bat
```

這會開啟一個選單，讓你選擇：
- 持續監控（每60分鐘檢查）
- 單次掃描
- 查看狀態
- 產生報告

### 方法 2：直接啟動持續監控
雙擊執行：
```
start_monitoring.bat
```

### 方法 3：使用命令列
```bash
# 啟動持續監控
python comprehensive_monitoring_integration.py start

# 執行單次掃描
python comprehensive_monitoring_integration.py start --interval 0

# 查看狀態
python comprehensive_monitoring_integration.py status

# 產生報告
python comprehensive_monitoring_integration.py report --type daily
```

## ⚙️ 設定檔配置

編輯 `config.json` 設定以下項目：

### 必要設定
```json
{
  "gemini_api_key": "你的 Gemini API Key",
  "email": {
    "smtp_server": "smtp.gmail.com",
    "smtp_port": 587,
    "sender_email": "你的Gmail",
    "sender_password": "你的應用程式密碼",
    "recipients": ["收件者1@email.com", "收件者2@email.com"]
  }
}
```

### Gmail 應用程式密碼設定
1. 前往 Google 帳戶設定
2. 安全性 → 兩步驟驗證
3. 應用程式密碼 → 產生新密碼
4. 將密碼填入 `sender_password`

## 🔄 自動化運行

### Windows 工作排程器設定
1. 開啟「工作排程器」
2. 建立基本工作
3. 名稱：「佛教教育網站監控」
4. 觸發程序：每日或每小時
5. 動作：啟動程式
   - 程式：`python.exe`
   - 引數：`comprehensive_monitoring_integration.py start`
   - 起始於：`D:\AIstudio\newinfo\ebook`

## 📁 輸出檔案位置

- **Word 摘要**：`generated_documents/`
- **Excel 資料**：`generated_documents/`
- **日誌檔案**：`logs/`
- **狀態資料**：`monitoring_data/`

## ⚠️ 注意事項

### 正常的警告訊息
執行時可能看到以下警告，這些都是正常的：
- `High memory usage` - 記憶體使用率高（Chrome 瀏覽器需要較多記憶體）
- `未找到書籍卡片元素` - 網站結構變化，系統會自動嘗試其他方式
- `QUOTA_EXCEEDED` - Chrome DevTools 的內部訊息，不影響功能

### 如果遇到問題
1. 檢查網路連線
2. 確認 Gemini API Key 有效
3. 確認 Email 設定正確
4. 查看 `logs/` 資料夾中的詳細日誌
