## 常見問題

### Q: 為什麼 status 命令顯示未初始化？
A: `status` 命令創建新實例來檢查，不會連接到運行中的進程。使用 `check_monitoring_status.py` 查看實際運行狀態。

### Q: 如何知道監控是否正常工作？
A: 檢查以下項目：
1. 運行 `python check_monitoring_status.py` 確認進程存在
2. 查看日誌檔案的最後修改時間
3. 檢查 `generated_documents/` 是否有新文件

### Q: 如何停止監控？
A: 三種方法：
1. 使用 `manage_monitoring.bat` 選項 3
2. 關閉監控視窗（如果可見）
3. 使用工作管理員結束 python.exe 進程

### Q: 監控會自動重啟嗎？
A: 不會。如果進程結束，需要手動重新啟動。建議使用 Windows 工作排程器設定自動啟動。

## 設定自動啟動

### Windows 工作排程器
1. 開啟「工作排程器」
2. 建立基本工作：「佛教教育網站監控」
3. 觸發程序：
   - 電腦啟動時
   - 或每日特定時間
4. 動作：
   - 程式：`python.exe`
   - 引數：`comprehensive_monitoring_integration.py start`
   - 起始於：`D:\AIstudio\newinfo\ebook`
5. 條件：
   - ✓ 只有在電腦使用 AC 電源時才啟動
   - ✓ 如果電腦改用電池電源，則停止
