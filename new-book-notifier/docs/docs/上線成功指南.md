## ⚙️ 必要設定

編輯 `config.json`：

```json
{
  "gemini_api_key": "你的 Gemini API Key",
  "email": {
    "smtp_server": "smtp.gmail.com",
    "smtp_port": 587,
    "sender_email": "你的Gmail",
    "sender_password": "應用程式密碼",
    "recipients": ["收件者@email.com"]
  }
}
```

### Gmail 應用程式密碼設定
1. Google 帳戶 → 安全性
2. 兩步驟驗證 → 開啟
3. 應用程式密碼 → 產生
4. 複製密碼到 `sender_password`
